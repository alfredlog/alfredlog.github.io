AgentTresor

Non-custodial spend control for AI agents. A company locks a budget in an on-chain vault; every payment needs both the agent's and the policy's signature. Per-agent rules, approvals for large payments, a hash-chained audit log – and agents like Claude, ChatGPT or Cursor connect via MCP and pay merchants over HTTP 402.

  • TypeScript
  • Node.js
  • MCP
  • Bitcoin Script
  • BSV mainnet
  • 270+ tests

E-Rechnung

An agent that receives, checks and approves German e-invoices (XRechnung, ZUGFeRD). It only decides alone when every value is grounded in the document and the official validation passes.
